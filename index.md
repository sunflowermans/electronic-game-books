# Flip less. Play more.

## What is Just The Games?

Just The Games is a fast, interactive reference for running tabletop RPGs from your browser. It extends the [Just The Docs](https://github.com/just-the-docs/just-the-docs) theme to facilitate play.

## Features

| d4     | Feature     |
| :---- | :--------- |
| 1      | Roll by clicking on random tables or in-line dice notation. 3d6 |
| 2      | Hover over [references](/docs/make-your-own/plugin-feature-overview.html#features) to preview, pin, or resize them. |
| 3      | Click directly on areas within [maps](/docs/make-your-own/adventure-template.html#map), diagrams, and dungeon layouts. |
| 4      | Write using [Markdown](https://raw.githubusercontent.com/sunflowermans/digital-gm/refs/heads/main/index.md). |

## How does it work?

All rules and adventures are written in simple Markdown, with support for more advanced layouts through HTML. The text is then converted into a website with some extra quality of life improvements for reading on a device. It works best on a computer, but you can use it on mobile for those times when a PDF just doesn't cut it.

The same extensions that power Just The Games can be used in any *Just the Docs* site. Like those used with [Cairn RPG](https://cairn.puzzledungeon.com/) or [The Designing Dungeons Course](https://dungeons.puzzledungeon.com). Click to see what they look like with the same plugins—and [play some games](https://cairn.puzzledungeon.com/adventures/first-party/)!

## Make stuff

Want to publish your own adventure or rules? Creators guides are available in [🔨 Make Your Own](/docs/make-your-own.html). You can host your own copy of Just The Games for free on GitHub in a few clicks by using this [template](https://github.com/sunflowermans/just-the-games-template).
