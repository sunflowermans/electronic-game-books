# Flip less. Play more.
{: .fs-9 }

Everything you need to run your game, optimized for quick reference. Use as-is or build your own in minutes.
{: .fs-6 .fw-300 }

![Window Preview](/assets/images/window-preview-demo-2.png)

## What is Just The Games?

Just The Games is a fast, interactive reference for running tabletop RPGs from your browser. It's [rules](/docs/ose-rules/), [adventures](/docs/a-familiar-tower/), [maps](/docs/seers-sanctum/#map), [monsters](/docs/a-familiar-tower/#biting-fly-giant), [notes](/docs/a-familiar-tower/#keys), [tables](/docs/a-familiar-tower/#wandering-encounters), and [handouts](/docs/seers-sanctum/#7-monkey-see) in one place that's built for the pace of the table.

## Features

| d4     | Feature     |
| :---- | :--------- |
| 1      | Roll by clicking on inline dice notation 3d6 or random tables. |
| 2      | Hover over [references](/docs/make-your-own/plugin-feature-overview/#features) to preview them. |
| 3      | Click directly on areas within [maps](/docs/make-your-own/adventure-template/#map), diagrams, and dungeon layouts. |
| 4      | Write using [Markdown](https://raw.githubusercontent.com/sunflowermans/digital-gm/refs/heads/main/index.md). |

## How does it work?

Just The Games turns Markdown documents into fast, interactive game references. Built on [Just The Docs](https://github.com/just-the-docs/just-the-docs) for Jekyll, it extends the theme with features designed specifically for running tabletop RPGs.

Everything is written in simple Markdown, with optional HTML for more advanced layouts and customization.

The same extensions that power Just The Games can be used in any *Just the Docs* site. Explore the [Cairn SRD](https://digital-cairn.pages.dev/) demo to see what's possible.

Want to publish your own adventure or rules? Read the [submission guide]() or you can [host your own copy of Just The Games]().
